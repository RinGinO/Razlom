# Разлом — памятка для сессий Claude

Браузерная стратегия скрытых ставок на 2–8 игроков. pnpm-монорепо на
TypeScript: `core` (правила, чистые функции) → `protocol` (сообщения, история)
→ `server` (ws, комнаты, SQLite) и `sim` (баланс); `client` (Vite + React,
пока хот-сит). Документация — [`docs/README.md`](docs/README.md).

## Жёсткие правила

- **Ничего не запускать на этой машине**: ни `pnpm dev`, ни сервер, ни
  preview — никаких открытых портов. Проект разворачивается на арендованном
  сервере. Тесты и `typecheck` запускать можно: они работают в процессе.
  Сокетный тест включается только там (`RAZLOM_SOCKET_TESTS=1`).
- **Всё на русском**: ответы, комментарии, документация, коммиты, тексты
  ошибок. Английский — только идентификаторы, ключи конфигов, цитаты вывода.
- **Коммитить и пушить — только по просьбе.**
- **Исходные правила не редактировать**: `docs/исходное/*.docx` — эталон.
  Толкование, принятое самостоятельно, записывается в
  `docs/написанное/толкования-правил.md`. Правила в **тестовой версии**:
  семь решений за автора ждут подтверждения.

## Проверка

```bash
pnpm typecheck && pnpm test     # 201 тест, 1 пропущенный (сокетный) — норма
```

Рабочая директория сохраняется между вызовами — используйте абсолютные пути
или `--root`, а не `cd packages/…`.

## Главное, что легко сломать

- Изменения правил — сначала в `packages/core` и тесте к нему.
- Вид игрока собирается **с нуля** из разрешённых полей (`server/src/project.ts`).
  Новое поле состояния соперникам не видно, пока его явно не добавят.
- `node:sqlite` грузится через `createRequire` — не менять на `import`.
- Фаз `reveal`, `resonance`, `upkeep` в реальной игре нет.
