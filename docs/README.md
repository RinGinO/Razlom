## Быстрый старт

```bash
pnpm install
pnpm test          # 201 тест
pnpm typecheck
pnpm sim           # отчёт по балансу
pnpm dev           # клиент в режиме хот-сит
```

Требуется Node 24 и pnpm 11. Нативных сборок нет: SQLite берётся встроенный
(`node:sqlite`).
