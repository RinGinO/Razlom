# Документация «Разлома»

Документы разделены по происхождению.

> ⚠ **Правила в тестовой версии.** Пятнадцать мест, где исходный текст молчал
> или спорил сам с собой, разрешены моими решениями — включая семь, принятых,
> чтобы доделать двенадцать карт. Всё работает и покрыто тестами, но это не
> канон: [список и цена пересмотра](написанное/толкования-правил.md#решения-за-автора).

Вся реализация сверяется с ними, ссылки в коде и в остальной документации
идут на их разделы (§).

| [`razlom-razrabotka.docx`](исходное/razlom-razrabotka.docx) | Спецификация разработки. Шестнадцать разделов: принципы, стек, модель домена, ядро, фазовый автомат, присутствие, протокол, проекции, персистентность, боты, симуляция баланса, клиент, безопасность, тестирование, порядок сборки, открытые вопросы. |

## Быстрый старт

```bash
pnpm install
pnpm test          # 201 тест
pnpm typecheck
pnpm sim           # отчёт по балансу
pnpm dev           # клиент в режиме хот-сит
```

Требуется Node 24 и pnpm 11. Нативных сборок нет: SQLite берётся встроенный
(`node:sqlite`).
