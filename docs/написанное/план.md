# План

Что делать дальше и в каком порядке. Порядок выбран так, чтобы как можно
раньше получить **играбельную по сети партию** — всё остальное без неё не
проверить на людях.

Подробности каждого пункта — в [незакрытом](незакрытое.md). Здесь только
очередь и критерии готовности.

---

## 1. Мелкие дыры протокола — до клиента

Сначала закрыть то, что клиент иначе упрётся в первые же дни.

- [ ] **Предзаявки по сети.** Поле `standingOrders` в `weavingSchema`,
  передача в `server.ts`, тесты. Рецепт — в
  [протоколе](протокол.md#предзаявки-не-доходят-по-сети).
  *Готово, когда:* сквозной тест в `fullmode.test.ts` проводит заявку
  Иллюзиониста через `clientMessageSchema` и видит перенос в событиях.
- [ ] **Решить, нужна ли ссылка на завершённую партию.** Если да — отдать
  `publicView()` по `GET /game/:code` или отдельным сообщением. Если нет —
  убрать `public` из `ServerMessage`, чтобы тип не обещал лишнего.

Объём — вечер.

## 2. Сетевой клиент — главное

Клиент сейчас хот-сит на ядре напрямую. Нужно перевести его на протокол.

- [ ] Слой соединения: `WebSocket`, переподключение с `rejoin`, `resync` по
  номеру версии, очередь исходящих до открытия сокета.
- [ ] Хранилище вида: снимок (`snapshot`/`patch`), готовность отдельно из
  `ready_map` ([почему](грабли.md#готовность-соперника--из-ready_map-не-из-снимка)),
  присутствие из `presence`.
- [ ] Экраны по макетам [`design/`](../../design/): лобби с кодом, драфт
  Архимагов, Плетение с обменами, целями и предзаявками, Раскрытие и Резонанс
  из событий ([фаз для них нет](грабли.md#фазы-которых-нет)),
  Строительство, итоги, история.
- [ ] Ошибки правил: код `RuleError` → человеческий текст.
- [ ] Хот-сит оставить как режим разработки или удалить — решить по ходу.

*Готово, когда:* на сервере двое в разных браузерах проводят партию от лобби
до итогов, один переподключается посреди Плетения и не теряет заявку.

## 3. Тесты клиента — вместе с пунктом 2, не после

- [ ] Vitest + Testing Library для слоя соединения и хранилища вида:
  подменный сокет, сценарии `resync`, отмены готовности, реконнекта.
- [ ] Тест, что клиент **не строит** вид сам из состояния — только из
  проекции сервера.

## 4. Первое развёртывание

Инструкция — в [развёртывании](развёртывание.md).

- [ ] Поднять на арендованном сервере, включить сокетный тест
  (`RAZLOM_SOCKET_TESTS=1`), убедиться, что он зелёный.
- [ ] Прокси с TLS перед сервером — браузеры не пустят `ws://` со страницы
  по `https://`.
- [ ] Резервная копия файла базы по расписанию.

## 5. Живые плейтесты и баланс

- [ ] Сыграть несколько партий живыми людьми. Записать, где непонятно и где
  скучно.
- [ ] **Решить противоречие §11** — что из целевых показателей главнее.
  Разбор и три выхода — в
  [толкованиях](толкования-правил.md#целевые-показатели-11-противоречат-друг-другу).
  До этого крутить коэффициент Порога бессмысленно.
- [ ] Пройтись по [семи решениям за автора](толкования-правил.md#решения-за-автора):
  подтвердить или заменить. Снять пометку «тестовая версия», когда все
  подтверждены.

## 6. Не горит

- [ ] **Агент симуляции уровня 3** (перебор исходов по §10) — чтобы
  абсолютные метрики зависели от правил, а не от агрессии агента. И научить
  агента активным картам: обменам, целям, предзаявкам.
- [ ] **Реванш** (§16): серия из трёх партий с общим счётом.
- [ ] **Push-уведомления**: сервер уже шлёт `your_turn`, нужны подписка и
  service worker на клиенте.
