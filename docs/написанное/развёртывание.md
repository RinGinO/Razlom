# Развёртывание

## Что нужно на сервере

- **Node 24.** Не ниже: используется встроенный `node:sqlite`.
- **pnpm 11.** Ставится через `corepack enable`.
- Ничего больше. Нативных сборок нет, компилятор не нужен, базы данных
  ставить не надо.

## Установка

```bash
git clone <репозиторий> && cd razlom
corepack enable
pnpm install
pnpm typecheck && pnpm test
```

## Первое, что стоит сделать после установки

Прогнать интеграционный тест через настоящие сокеты. Он написан, но локально
пропускается: восемь игроков доигрывают партию, двоим рвут соединение, они
возвращаются по ключу.

```bash
RAZLOM_SOCKET_TESTS=1 pnpm --filter @razlom/server test
```

Это единственная часть системы, не проверенная в работе.

## Запуск

```bash
PORT=8787 RAZLOM_DB=/var/lib/razlom/razlom.db \
  pnpm --filter @razlom/server start
```

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `PORT` | `8787` | порт WebSocket |
| `RAZLOM_DB` | `./razlom.db` | файл базы |

Сервер корректно закрывается по `SIGTERM` и `SIGINT`, так что под systemd
встаёт без сюрпризов.

## Пример unit-файла

```ini
[Unit]
Description=Разлом
After=network.target

[Service]
Type=simple
User=razlom
WorkingDirectory=/opt/razlom
Environment=PORT=8787
Environment=RAZLOM_DB=/var/lib/razlom/razlom.db
ExecStart=/usr/bin/pnpm --filter @razlom/server start
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

## База

Один файл плюс `-wal` и `-shm` рядом. Бэкап — копия файла при
остановленном сервисе либо `sqlite3 razlom.db ".backup"` на живом.
`.gitignore` их не пустит в репозиторий.

Комнаты без движения дольше тридцати суток уходят в архив; уборка идёт раз в
час и процесс не держит. У завершённой партии остаётся только последний снимок.

## Чего пока нет

**Клиента к этому серверу нет** — он работает в хот-сите и о сокетах не знает.
Развернуть сервер можно, играть по сети пока нельзя.

HTTPS и WSS не настраиваются самим сервером: предполагается обратный прокси
(nginx, Caddy) — он же отдаёт статику клиента, когда та появится.
