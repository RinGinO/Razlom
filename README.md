# Разлом

Соревновательная стратегия скрытых ставок на 2–8 игроков. Браузерная,
многопользовательская, без ограничений по времени на ход.

Раз в столетие открывается Разлом — источник сырой магии. Архимаги слетаются
к нему, чтобы вобрать как можно больше эссенции, пока трещина не затянулась.
Узел, в который вцепились слишком многие, схлопывается и выжигает Скверной
всех присутствующих. Вы не соревнуетесь в силе — вы угадываете чужую жадность.

## Быстрый старт

```bash
corepack enable
pnpm install
pnpm test        # 201 тест
pnpm typecheck
pnpm sim         # отчёт по балансу
pnpm dev         # клиент, режим хот-сит
```

Нужен Node 24. Нативных сборок нет.

## Состояние

Все семь этапов спецификации пройдены. Правила реализованы целиком — все
тридцать Чар и восемь Архимагов, — сервер держит комнаты, скрытые ставки и
постоянство, симуляция считает баланс.

> ⚠ **Правила в тестовой версии.** Двенадцать карт доделаны по решениям,
> принятым за автора там, где исходный текст молчал. Они играбельны и покрыты
> тестами, но подлежат пересмотру:
> [решения за автора](docs/написанное/толкования-правил.md#решения-за-автора).

**Клиент к сети пока не подключён** — работает в режиме хот-сит. Это самая
крупная незакрытая часть, подробности в
[docs/написанное/незакрытое.md](docs/написанное/незакрытое.md).

## Структура

```
packages/core       правила: чистые функции, ноль зависимостей
packages/protocol   сообщения, схемы, проекции
packages/server     комнаты, сокеты, SQLite
packages/sim        симуляция баланса
packages/client     интерфейс
design/             макеты интерфейса
docs/               документация
```
