# Дизайн-макеты «Разлома»

Исходники холста, опубликованного как артефакт:
https://claude.ai/code/artifact/830c806b-82cd-4710-8870-f55d098136a9

## Что где

- `*.dc.html` — артборды, по файлу на экран
- `canvas.json` — раскладка холста: страницы, позиции, заметки
- `gen-*.mjs` — генераторы артбордов; запускать **из этой папки**,
  они пишут рядом с собой
- `razlom-glavnyy-ekran.html` — собранный холст, который уходит в артефакт

## Пересборка

```
node gen-rift.mjs      # экраны варианта Д
node gen-phases.mjs    # Раскрытие и Резонанс
node gen-more.mjs      # Возврат, Строительство, Схождение, Итоги
node gen-rest.mjs      # Лобби, Драфт, состояния поля
```

Затем пересобрать холст помощником из скилла `design` и опубликовать.
Файл переехал из корня, поэтому при следующей публикации нужно указывать
**существующий URL артефакта**, иначе создастся отдельный артефакт.
